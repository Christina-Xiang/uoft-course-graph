# MAT309H1 — 关键公式速查

## 一、命题逻辑

| 连接词 | 符号 | 真值条件 |
|--------|------|---------|
| 否定 | $\neg p$ | $p$ 为假 |
| 合取 | $p\wedge q$ | 两者为真 |
| 析取 | $p\vee q$ | 至少一个为真 |
| 蕴含 | $p\rightarrow q$ | $p$ 假或 $q$ 真 |
| 等价 | $p\leftrightarrow q$ | 同真同假 |

## 二、一阶逻辑

| 概念 | 定义 |
|------|------|
| 全称量词 | $\forall x\, P(x)$ |
| 存在量词 | $\exists x\, P(x)$ |
| 前束范式 | 所有量词前置的公式 |
| Skolem 化 | 消去存在量词（引入 Skolem 函数）|

## 三、可计算性

| 概念 | 定义 |
|------|------|
| Turing 机 | 形式化计算模型 |
| 可判定性 | 存在算法判定命题真假 |
| 不可判定性 | 不存在这样的算法（停机问题）|
| Gödel 不完备 | 足够强的形式系统必然不完备或不一致 |
