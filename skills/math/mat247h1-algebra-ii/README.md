# MAT247H1 — Algebra II

UofT · Math · Half Credit

## About

This skill package provides three teaching modes for mastering MAT247H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of modules over a PID and their structure |
| Deductive | `deductive.json` | Step-by-step derivation of Rational Canonical Form via invariant factors |
| Correction | `correction.json` | Fixing the error: confusing Jordan canonical form with rational canonical form |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/math/mat247h1-algebra-ii ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/math/mat247h1-algebra-ii ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/math/mat247h1-algebra-ii/SKILL.md
```
