# MAT237Y1 — Multivariable Calculus with Proofs

UofT · Math · Full Year Credit

## About

This skill package provides three teaching modes for mastering MAT237Y1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of topology of $\mathbb{R}^n$ |
| Deductive | `deductive.json` | Step-by-step derivation of Implicit Function Theorem |
| Correction | `correction.json` | Fixing the error: confusing path-connected with connected |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/math/mat237y1-multivariable-calculus-with-proofs ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/math/mat237y1-multivariable-calculus-with-proofs ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/math/mat237y1-multivariable-calculus-with-proofs/SKILL.md
```
