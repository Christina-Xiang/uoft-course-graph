# MAT301H1 — Groups and Symmetries

UofT · Math · Half Credit

## About

This skill package provides three teaching modes for mastering MAT301H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of symmetry as a group |
| Deductive | `deductive.json` | Step-by-step derivation of Lagrange's Theorem: $|H|$ divides $|G|$ |
| Correction | `correction.json` | Fixing the error: assuming all groups are abelian |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/math/mat301h1-groups-and-symmetries ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/math/mat301h1-groups-and-symmetries ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/math/mat301h1-groups-and-symmetries/SKILL.md
```
