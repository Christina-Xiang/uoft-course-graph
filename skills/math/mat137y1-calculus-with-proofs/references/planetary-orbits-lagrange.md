## 第一部分：行星椭圆轨道（开普勒第一定律）

### 1.1 物理设定

```
太阳（质量 M）位于原点
行星（质量 m）的位置向量 r(t) = (r cosθ, r sinθ)
万有引力：F = -GMm/r² · r̂（指向太阳）
```

### 1.2 极坐标下的运动方程

**应用 Skill-A3（符号运算）**，将牛顿第二定律写为极坐标形式。

位置向量：
```
r = r · r̂
```

速度（链式法则，Skill-B3）：
```
v = dr/dt = ṙ · r̂ + r · θ̇ · θ̂
```

加速度（再次求导）：
```
a = (r̈ - rθ̇²) · r̂ + (rθ̈ + 2ṙθ̇) · θ̂
```

牛顿第二定律 F = ma，引力只有径向分量：
```
径向：    m(r̈ - rθ̇²) = -GMm/r²    (1)
横向：    m(rθ̈ + 2ṙθ̇) = 0         (2)
```

### 1.3 角动量守恒

**应用 Skill-B3（微分技术）**。方程 (2) 可写为：
```
rθ̈ + 2ṙθ̇ = (1/r) · d(r²θ̇)/dt = 0
```

两边乘 r：
```
d(r²θ̇)/dt = 0  ⇒  r²θ̇ = h  （常数）
```

其中 `h = 角动量/m`，这就是**开普勒第二定律**的影子——单位时间扫过面积相等。

**掌握的技能点（Skill-B3 L4）**：识别出 `d(r²θ̇)/dt` 这种形式的导数，理解角动量守恒来源于力的中心对称性。

### 1.4 化为一维问题

**应用 Skill-C2（问题建模）**。作变量替换 u = 1/r，用 u 表达 θ 的导数。

链式法则：
```
ṙ = dr/dt = dr/dθ · θ̇ = (-1/u²)(du/dθ) · h/r² = -h(du/dθ)
```

这里用了 r = 1/u, ṙ = -(1/u²)u̇ = -(1/u²)(du/dθ)θ̇ = -(1/u²)(du/dθ)h/r² = -h(du/dθ)

二阶导数：
```
r̈ = d/dt[-h(du/dθ)] = -h(d²u/dθ²) · θ̇ = -h²u²(d²u/dθ²)
```

代入径向方程 (1)：
```
-h²u²(d²u/dθ²) - (1/u)(h²u⁴) = -GMu²
```

化简得关键方程：
```
d²u/dθ² + u = GM/h²
```

**掌握的技能点（Skill-A3 L5）**：在复杂变量替换中保持计算准确，不遗漏链式法则的每一步。

### 1.5 求解轨道微分方程

**应用 Skill-B4（积分技术）**。这是一个二阶线性非齐次常微分方程，通解为：
```
u(θ) = Acosθ + Bsinθ + GM/h²
```

令 ε = 偏心率，选坐标轴使近日点位于 θ = 0：
```
u(θ) = (GM/h²)(1 + ε cosθ)
```

回到 r = 1/u：
```
r(θ) = (h²/GM) / (1 + ε cosθ)
```

这即为**圆锥曲线标准形式**（焦点在原点）。

令半正焦弦 ℓ = h²/GM：
```
r(θ) = ℓ / (1 + ε cosθ)
```

**椭圆条件**：0 ≤ ε < 1
- ε = 0 → 正圆
- 0 < ε < 1 → 椭圆
- ε = 1 → 抛物线（逃逸轨道）
- ε > 1 → 双曲线（过境轨道）

**掌握的技能点（Skill-B4 L4）**：识别该 ODE 为简谐振动方程，直接写出通解。

### 1.6 椭圆几何参数

```
半长轴 a = ℓ/(1-ε²)
半短轴 b = a√(1-ε²)
太阳位于右焦点：c = aε
距离范围：近日点 r_min = a(1-ε)，远日点 r_max = a(1+ε)
```

### 1.7 证明小结

| 步骤 | 使用技能 |
|------|----------|
| 极坐标下的加速度分解 | Skill-A3 符号运算 |
| 求导得角动量守恒 | Skill-B3 微分技术 |
| 变量替换 u = 1/r | Skill-C2 问题建模 |
| ODE 求解 | Skill-B4 积分技术 |
| 证明结果为圆锥曲线 | Skill-C1 证明构造 + Skill-B6 级数展开 |

## 第二部分：拉格朗日点

### 2.1 问题设定

```
两个大质量天体（太阳 M₁ 和地球 M₂）绕质心做圆周运动
第三个小质量天体（航天器 m ≪ M₁, M₂）在该系统中运动
m 对 M₁、M₂ 的引力影响可忽略
```

### 2.2 旋转坐标系

**应用 Skill-C2（问题建模）**。选择以角速度 ω 旋转的坐标系，使 M₁ 和 M₂ 固定在 x 轴上。

设 M₁ 在 (-x₁, 0)，M₂ 在 (x₂, 0)，其中：
```
x₁ = a · M₂/(M₁+M₂)
x₂ = a · M₁/(M₁+M₂)
```
(a = 两星距离)

**应用 Skill-B3（微分技术）**。在旋转坐标系中，航天器的有效势能为：
```
U_eff = -GM₁/|r - r₁| - GM₂/|r - r₂| - (1/2)ω²(x² + y²)
```

三项的物理含义：
1. M₁ 的引力势
2. M₂ 的引力势
3. 离心势（来自旋转坐标系）

### 2.3 拉格朗日点的条件

**应用 Skill-B1（极限分析）**：平衡点处有效势的梯度为零：
```
∂U_eff/∂x = 0,    ∂U_eff/∂y = 0
```

这等价于：
```
GM₁(x - x₁)/|r - r₁|³ + GM₂(x - x₂)/|r - r₂|³ - ω²x = 0
GM₁ y/|r - r₁|³ + GM₂ y/|r - r₂|³ - ω²y = 0
```

### 2.4 L1、L2、L3（共线拉格朗日点）

**应用 Skill-A1（形式化定义）**。在 x 轴上（y = 0）：

方程简化为：
```
GM₁/(x - x₁)² - GM₂/(x - x₂)² - ω²x = 0
```

三个解分别位于：
- **L1**：M₁ 和 M₂ 之间
- **L2**：M₂ 外侧
- **L3**：M₁ 外侧（远离 M₂ 一侧）

**应用 Skill-B6（级数展开 + 泰勒近似）**。对于 L2 点（距地球约 150 万公里）：

设 d = 该点到地球的距离，d ≪ a，泰勒展开后可得近似解：
```
d ≈ a · (M₂/3M₁)^{1/3}
```

代入太阳-地球系统：
```
M₁ = 1.989×10³⁰ kg
M₂ = 5.972×10²⁴ kg
a = 1.496×10¹¹ m（1 AU）

d ≈ 1.496×10¹¹ · (5.972×10²⁴ / 3·1.989×10³⁰)^{1/3}
  ≈ 1.496×10¹¹ · 0.01
  ≈ 1.5×10⁹ m ≈ 150 万公里
```

**掌握应用（Skill-C3 误差控制 L3）**：理解泰勒展开的一阶近似足够准确，截断误差在 1% 以内。

### 2.5 L4 和 L5（三角拉格朗日点）

**应用 Skill-C1（证明构造）**。考虑 y ≠ 0 的情形。
设 r₁ = |r - r₁|, r₂ = |r - r₂|。

对于 L4/L5，三个天体构成等边三角形：
```
r₁ = r₂ = a
```

验证：当 r₁ = r₂ = a 时，
- 离心力与引力的合力恰好为零
- 航天器位于正三角形的顶点

位置坐标：
```
L4: (a/2 · (M₁-M₂)/(M₁+M₂), √3/2 · a)
L5: (a/2 · (M₁-M₂)/(M₁+M₂), -√3/2 · a)
```

**掌握应用（Skill-A4 反例思维 L3）**：L4/L5 的稳定性需要满足条件——当 M₁/M₂ > 24.96 时稳定。太阳-地球系统（M₁/M₂ ≈ 333,000）远大于该阈值，因此 L4/L5 稳定。

### 2.5 各点位置示意图

```
                     L4 (等边三角形顶点)
                        ◈
                        |
     L3 ———— M₁ ———— L1 ———— M₂ ———— L2
                        |
                        ◈
                     L5 (等边三角形顶点)
```

| 点 | 位置 | 实际应用 |
|----|------|----------|
| L1 | 太阳与地球之间 | 太阳观测卫星（SOHO） |
