# MAT267H1 — Advanced Ordinary Differential Equations

UofT · Math · Half Credit

## About

This skill package provides three teaching modes for mastering MAT267H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of phase portraits of nonlinear systems |
| Deductive | `deductive.json` | Step-by-step derivation of Poincaré–Bendixson Theorem |
| Correction | `correction.json` | Fixing the error: assuming linear stability guarantees nonlinear stability |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/math/mat267h1-advanced-ordinary-differential-equations ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/math/mat267h1-advanced-ordinary-differential-equations ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/math/mat267h1-advanced-ordinary-differential-equations/SKILL.md
```
