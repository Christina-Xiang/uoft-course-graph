# STA414H1 — Statistical Methods for Machine Learning II

UofT · Stats · Half Credit

## About

This skill package provides three teaching modes for mastering STA414H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of the representational power of depth |
| Deductive | `deductive.json` | Step-by-step derivation of backpropagation as the chain rule |
| Correction | `correction.json` | Fixing the error: Gaussian processes always use the RBF kernel |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/stats/sta414h1-statistical-methods-for-machine-learning-ii ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/stats/sta414h1-statistical-methods-for-machine-learning-ii ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/stats/sta414h1-statistical-methods-for-machine-learning-ii/SKILL.md
```
