# STA347H1 — Probability

UofT · Stats · Half Credit

## About

This skill package provides three teaching modes for mastering STA347H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of what is a probability measure |
| Deductive | `deductive.json` | Step-by-step derivation of Kolmogorov's Three Series Theorem for almost sure convergence of sums |
| Correction | `correction.json` | Fixing the error: confusing $\sigma$-algebras with partitions of $\Omega$ |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/stats/sta347h1-probability ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/stats/sta347h1-probability ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/stats/sta347h1-probability/SKILL.md
```
