# STA302H1 — Methods of Data Analysis I

UofT · Stats · Half Credit

## About

This skill package provides three teaching modes for mastering STA302H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of the geometry of least squares |
| Deductive | `deductive.json` | Step-by-step derivation of Gauss-Markov Theorem |
| Correction | `correction.json` | Fixing the error: $R^2$ alone determines model quality |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/stats/sta302h1-methods-of-data-analysis-i ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/stats/sta302h1-methods-of-data-analysis-i ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/stats/sta302h1-methods-of-data-analysis-i/SKILL.md
```
