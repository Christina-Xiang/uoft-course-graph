# STA303H1 — Methods of Data Analysis II

UofT · Stats · Half Credit

## About

This skill package provides three teaching modes for mastering STA303H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of hierarchical structure in data |
| Deductive | `deductive.json` | Step-by-step derivation of the EM algorithm for mixed models |
| Correction | `correction.json` | Fixing the error: ignoring random effects and treating all observations as independent |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/stats/sta303h1-methods-of-data-analysis-ii ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/stats/sta303h1-methods-of-data-analysis-ii ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/stats/sta303h1-methods-of-data-analysis-ii/SKILL.md
```
