# STA304H1 — Surveys, Sampling and Observational Data

UofT · Stats · Half Credit

## About

This skill package provides three teaching modes for mastering STA304H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of bias in surveys |
| Deductive | `deductive.json` | Step-by-step derivation of Horvitz-Thompson estimator |
| Correction | `correction.json` | Fixing the error: correlation implies causation in observational studies |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/stats/sta304h1-surveys-sampling-and-observational-data ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/stats/sta304h1-surveys-sampling-and-observational-data ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/stats/sta304h1-surveys-sampling-and-observational-data/SKILL.md
```
