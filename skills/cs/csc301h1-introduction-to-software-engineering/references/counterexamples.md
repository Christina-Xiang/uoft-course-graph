# CSC301H1 — 常见错误与反例

| # | 常见错误 | 说明 |
|---|---------|------|
| 1 | **继承滥用** | 为了复用代码而继承, 违反 LSP |
| 2 | **上帝类 (God Class)** | 一个类承担过多职责, 违反 SRP |
| 3 | **面条代码 (Spaghetti Code)** | 没有结构, 跳转混乱 |
| 4 | **魔法数字** | 硬编码值, 不可维护 |
| 5 | **过度工程** | 为不存在的需求引入复杂架构 |
| 6 | **测试覆盖误区** | 100% 覆盖不能保证无 bug |
| 7 | **忘记处理边界情况** | 空输入、null、超大值 |
| 8 | **紧耦合** | 一个模块的改动引发连锁修改 |
| 9 | **数据库死锁** | 事务交叉等待 |
| 10 | **安全漏洞** | SQL 注入、XSS、CSRF |
| 11 | **框架锁定** | 业务代码深度依赖框架 API |
| 12 | **YAGNI 违反** | 实现不需要的功能增加维护成本 |
| 13 | **过早优化** | 未分析瓶颈就优化代码 |
| 14 | **魔法字符串** | 相同字符串重复出现, 改为常量 |
