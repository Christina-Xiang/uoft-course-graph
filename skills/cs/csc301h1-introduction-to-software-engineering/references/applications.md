# CSC301H1 — 实际应用

- **Web 应用**: React + Spring Boot REST API
- **移动应用**: Android/iOS 原生或 Flutter 跨平台
- **微服务**: 服务拆分 + Docker + Kubernetes 部署
- **CI/CD**: GitHub Actions / Jenkins 自动构建部署
- **API Gateway**: 统一入口、认证、限流
- **消息队列**: Kafka / RabbitMQ 异步解耦
- **数据库**: PostgreSQL / MongoDB 持久化存储
- **缓存**: Redis 提高读取性能
- **搜索引擎**: Elasticsearch 全文搜索
- **版本管理**: Git 分支策略 (GitFlow / GitHub Flow)
- **代码审查**: PR Review 确保代码质量
- **文档即代码**: Swagger / OpenAPI 自动生成文档
- **监控告警**: Prometheus + Grafana 系统观测
- **日志**: ELK Stack (Elasticsearch + Logstash + Kibana)
- **混沌工程**: 主动注入故障验证系统韧性
