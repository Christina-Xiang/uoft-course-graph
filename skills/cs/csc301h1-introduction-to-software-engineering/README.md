# CSC301H1 — Introduction to Software Engineering

UofT · CS · Half Credit

## About

This skill package provides three teaching modes for mastering CSC301H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of requirements engineering |
| Deductive | `deductive.json` | Step-by-step derivation of COCOMO cost estimation model |
| Correction | `correction.json` | Fixing the error: agile means no planning |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/cs/csc301h1-introduction-to-software-engineering ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/cs/csc301h1-introduction-to-software-engineering ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/cs/csc301h1-introduction-to-software-engineering/SKILL.md
```
