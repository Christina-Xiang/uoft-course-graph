# CSC236H1 — Introduction to the Theory of Computation

UofT · CS · Half Credit

## About

This skill package provides three teaching modes for mastering CSC236H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of finite automata and regular languages |
| Deductive | `deductive.json` | Step-by-step derivation of Pumping Lemma for regular languages |
| Correction | `correction.json` | Fixing the error: confusing decidability with recognisability |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/cs/csc236h1-introduction-to-the-theory-of-computation ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/cs/csc236h1-introduction-to-the-theory-of-computation ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/cs/csc236h1-introduction-to-the-theory-of-computation/SKILL.md
```
