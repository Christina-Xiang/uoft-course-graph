# CSC148H1 — 常见错误与反例

| # | 常见错误 | 说明 |
|---|---------|------|
| 1 | **无限递归** | 无基础情况导致栈溢出 |
| 2 | **递归重复计算** | Fibonacci 朴素递归 $O(2^n)$ |
| 3 | **哈希碰撞** | 坏哈希函数导致退化到 $O(n)$ |
| 4 | **BST 退化** | 有序插入变成链表 $O(n^2)$ |
| 5 | **浅拷贝陷阱** | 列表嵌套列表复制只复制引用 |
| 6 | **继承滥用** | 不合理的 IS-A 关系导致脆弱的基类 |
| 7 | **可变类型作为哈希键** | list 不可哈希 |
| 8 | **并行修改** | 遍历列表时删除元素引发异常 |
| 9 | **相等 vs 同一** | $\text{__eq__}$ vs $\text{is}$ |
| 10 | **快速排序最坏** | 已有序 + 固定基准 |
| 11 | **ADT 泄露** | 返回内部可变引用破坏封装 |
