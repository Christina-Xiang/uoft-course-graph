# CSC207H1 — Software Design

UofT · CS · Half Credit

## About

This skill package provides three teaching modes for mastering CSC207H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of encapsulation |
| Deductive | `deductive.json` | Step-by-step derivation of Liskov Substitution Principle |
| Correction | `correction.json` | Fixing the error: inheritance overuse — the 'fragile base class' problem |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/cs/csc207h1-software-design ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/cs/csc207h1-software-design ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/cs/csc207h1-software-design/SKILL.md
```
