# CSC311H1 — Introduction to Machine Learning

UofT · CS · Half Credit

## About

This skill package provides three teaching modes for mastering CSC311H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of the fundamental problem of ML |
| Deductive | `deductive.json` | Step-by-step derivation of VC-dimension and generalisation |
| Correction | `correction.json` | Fixing the error: training accuracy measures real-world performance |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/cs/csc311h1-introduction-to-machine-learning ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/cs/csc311h1-introduction-to-machine-learning ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/cs/csc311h1-introduction-to-machine-learning/SKILL.md
```
