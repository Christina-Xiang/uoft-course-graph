# CSC311H1 — 常见错误与反例

| # | 常见错误 | 说明 |
|---|---------|------|
| 1 | **过拟合** | 复杂模型在训练集上完美但测试集表现差 |
| 2 | **欠拟合** | 模型太简单无法捕获数据模式 |
| 3 | **数据泄露** | 测试集信息不小心用于训练 |
| 4 | **类别不平衡** | 多数类主导损失函数 |
| 5 | **梯度消失** | 深层网络 Sigmoid 激活梯度衰减到 0 |
| 6 | **梯度爆炸** | 梯度指数增长导致权重发散 |
| 7 | **模式坍塌** | GAN 生成器只产生少数几种输出 |
| 8 | **非凸优化** | 神经网络损失面存在大量局部最小值 |
| 9 | **K-means 对初始值敏感** | 不同初始化得到不同聚类结果 |
| 10 | **维数灾难** | 高维空间中距离度量失效, 所有点几乎等距 |
| 11 | **过拟合交叉验证** | 多次使用 CV 选择模型导致信息泄露 |
| 12 | **伪相关 (混淆变量)** | $x$ 和 $y$ 都受 $z$ 影响 |
| 13 | **SVM 核选择不当** | RBF 核 $\gamma$ 太大过拟合, 太小欠拟合 |
| 14 | **学习率太高** | 损失爆炸不收敛; 学习率太低: 收敛极慢 |
| 15 | **决策树过深** | 完全记忆训练集, 无泛化能力 |
