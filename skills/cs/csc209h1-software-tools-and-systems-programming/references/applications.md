# CSC209H1 — 实际应用

- **操作系统**: Linux 内核进程管理、内存管理、文件系统
- **Web 服务器**: Apache/Nginx 并发处理 HTTP 请求
- **数据库**: MySQL Buffer Pool 管理 + 事务隔离
- **云计算**: 虚拟化 (KVM) 资源隔离 + 调度
- **容器**: Docker / Linux Namespace + Cgroup
- **嵌入式**: RTOS 实时调度, 资源受限环境
- **高性能计算**: MPI 并行计算, NUMA 架构优化
- **文件系统**: ext4 日志式文件系统, 崩溃恢复
- **Shell**: bash 脚本自动化系统管理
- **网络服务**: Socket 编程实现 HTTP/FTP 服务器
- **监控系统**: top/htop/ps 查看进程状态
- **调试工具**: GDB 调试段错误, strace 系统调用追踪
- **性能分析**: perf / Valgrind 分析 CPU/内存
- **分布式**: MapReduce / Spark 并行数据计算
