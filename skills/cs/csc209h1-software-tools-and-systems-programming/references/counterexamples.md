# CSC209H1 — 常见错误与反例

| # | 常见错误 | 说明 |
|---|---------|------|
| 1 | **死锁** | 四个必要条件同时满足, 例如两个进程各自锁了一个资源并等待对方 |
| 2 | **竞态条件** | 无锁并发访问共享变量导致结果不确定 |
| 3 | **内存泄露** | malloc 后未 free, 逐渐耗尽内存 |
| 4 | **悬空指针** | free 后继续使用指针, 访问非法内存 |
| 5 | **缓冲区溢出** | 输入越界覆盖相邻内存数据 |
| 6 | **段错误** | 访问非法内存地址 (NULL 解引用) |
| 7 | **僵尸进程** | 父进程未 wait 子进程就退出, 子进程残留进程表 |
| 8 | **孤儿进程** | 父进程先退出, 子进程被 init 收养 |
| 9 | **信号丢失** | 不可靠信号 (SIGUSR1) 可能被同类型后续信号覆盖 |
| 10 | **线程不安全** | 多个线程同时修改未加锁的全局变量 |
| 11 | **虚假唤醒** | condition wait 可能在没有 signal 时返回 |
| 12 | **优先级反转** | 低优先级线程持有高优先级需要的锁 |
| 13 | **TLB 抖动** | 进程频繁切换导致 TLB 刷新率高 |
| 14 | **Belady 异常** | FIFO 缺页率随物理页框数增加而增加 |
| 15 | **磁盘碎片** | 频繁创建删除文件导致外部碎片 |
