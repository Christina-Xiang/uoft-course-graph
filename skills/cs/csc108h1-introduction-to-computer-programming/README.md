# CSC108H1 — Introduction to Computer Programming

UofT · CS · Half Credit

## About

This skill package provides three teaching modes for mastering CSC108H1:

| Mode | File | Description |
|------|------|-------------|
| Socratic | `socratic.json` | Guided discovery of what is a variable |
| Deductive | `deductive.json` | Step-by-step derivation of binary search correctness |
| Correction | `correction.json` | Fixing the error: $==$ vs $=$ for assignment vs comparison |

Each mode is also documented in `SKILL.md` as the Anthropic Skills entry point.

## Installation

**Claude Code / OpenCode:**
```
cp -r skills/cs/csc108h1-introduction-to-computer-programming ~/.claude/skills/
```
or for OpenCode:
```
cp -r skills/cs/csc108h1-introduction-to-computer-programming ~/.opencode/agent/skills/
```

Restart your agent, then invoke:
```
agent run skills/cs/csc108h1-introduction-to-computer-programming/SKILL.md
```
