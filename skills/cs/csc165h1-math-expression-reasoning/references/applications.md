# CSC165H1 — 实际应用

- **编译器**: 词法分析 (DFA/正则表达式) + 语法分析 (CFG/PDA)
- **静态分析**: 抽象解释验证程序性质
- **算法分析**: 渐进复杂度比较排序/搜索算法
- **程序验证**: 循环不变量 + Hoare Logic 证明正确性
- **密码学**: 计算复杂性理论保证安全性下界
- **自动机**: 文本搜索 (KMP 基于 DFA)
- **正则表达式**: grep, sed, Python re 等文本处理
- **网络协议验证**: 有限状态机建模协议行为
- **编程语言**: 类型系统 CFG/LALR/LL 解析
- **人工智能**: 逻辑推理 (命题/谓词逻辑)
- **生物信息学**: CYK 算法解析 RNA 二级结构
- **最优化**: 整数规划 NP-Complete, 启发式求解

## 培养技能
